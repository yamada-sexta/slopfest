A small machine with an unknown beginning

Many beginnings.
One meeting place.

You don’t know which state the machine is in. Press a button: it moves every possible state at once. Can you make them all meet?

The machine

    Lit states are still possible. Dim states have been ruled out.

    See what each button does

    Read across a row: from that state, a button sends you to the listed destination.

    Where the paths meet

    Each colored path begins at a different state. White dots show the possibilities that remain. Rows are states; columns are button presses. Long traces wrap every twelve presses.

    Make your own machine

    Use 1–10 states and 1–4 buttons named with lowercase letters. Each array lists the destination from states 0, 1, 2, and so on. Applying a machine starts a fresh trace.

    A little help with the clock

    Button a moves one state clockwise. Button b sends the last state to zero and leaves the others in place. Repeating b alone won’t finish the job. Turn the clock between gate presses to bring more states together.

    Hints search every reachable set of possible states, starting from where you are now. They give a shortest remaining route, with alphabetic tie breaking. The carousel only rearranges states, so it cannot merge any of them.
