What is the trick?

A mess with
an exact inverse.

The grid turns little groups of four squares. After each step, the groups shift by one square. The turn depends on the group’s position and how many ink cells it holds.

To go backward, the machine uses the previous grouping and reverses its turns. Every ink color keeps exactly the same number of cells. The starting thumbnail is kept for comparison; the animation keeps no frame history.
