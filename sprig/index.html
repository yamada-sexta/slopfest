Each generation replaces all symbols at once. The final word is read as a path. Little rules become large, surprising shapes.

seed XStart with a word.
rule X -> F[+X][-X]Replace X on every generation.
F   M   .Draw forward, move without drawing, place a bud.
+   -   |Turn right, turn left, turn around.
[   ]Remember a position. Return to it.
X   Y   …Other letters rewrite silently.
