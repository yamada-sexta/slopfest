Why can it come home?

An ordinary cellular rule looks at each bit and its two neighbors. Some rules lose information. Backstitch keeps a second row and changes the recipe:

next = past XOR F(current)
previous = current XOR F(past)

XOR twice cancels. All 256 rules can reverse on pairs. The cloth is a drawing; erasing it leaves the live pair intact. Both live rows are compared at home.

This is a second-order machine, rather than ordinary rule 110 running backward. No accounts, saved drafts, or network calls.
