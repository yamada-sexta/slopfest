# Slopfest 0.1.0 — A cabinet, a ghost, a seed

The first two experiments are ready to play with:

- **Afterimage:** five turn-based puzzle rooms where recorded versions of your
  past self hold doors open for your present self.
- **Sprig:** a small rewrite language with five specimens, a live editor, three
  palettes, and SVG export. The source also includes a command line interpreter.

The browser bundle includes the gallery and both projects, with no accounts,
tracking, external fonts, or dependency installation. Extract the release ZIP and
serve it over HTTP, for example with `python3 -m http.server --bind 127.0.0.1`.
To use the command line interpreter or run tests, use the source archive instead.

This release establishes portable build, verification, Pages, and release workflows.
All five puzzle solutions and language specimens are covered by automated tests.
